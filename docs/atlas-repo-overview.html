How the repo fits together

This page maps the three living systems in the repo: the on-device game, the always-running place pipeline, and the APK test harness. It also includes the release/export flow and the native shell pieces that keep Android behaving like a real app.

What matters most

Game logic stays local. Server calls are only for leaderboard, stats, tickets, notifications, and place pipeline.
